# Contributing to Swift Menu Duplicator

Thank you for your interest in contributing to Swift Menu Duplicator!

## Ways to Contribute

- **Report bugs**: Open an issue on GitHub
- **Suggest features**: Create a feature request
- **Translate**: Help translate the plugin into your language
- **Code contributions**: Submit pull requests

## Development Setup

1. Clone the repository
2. Install dependencies: `composer install`
3. Run tests: `./vendor/bin/phpunit`
4. Run code style checks: `./vendor/bin/phpcs --standard=phpcs.xml.dist includes/`

## Coding Standards

- Follow WordPress Coding Standards
- Use PHP 7.4+ syntax
- Add PHPDoc comments for all public methods
- Escape all output, sanitize all input
